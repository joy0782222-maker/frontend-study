# 🛍️ RE:MAIND 쇼핑몰 메인 페이지

> 의류 쇼핑몰 메인 화면을 HTML · CSS로 따라 만들어보기 (2026.09.30)

<br>

## ✨ 페이지 구성

- **헤더** — 쇼핑몰 로고
- **상단 메뉴** — NOTICE · REVIEW · QnA
- **카테고리 메뉴** — 당일발송 · BEST · NEW · OUTER · TOP · BOTTOM ...
- **메인 배너** 이미지
- **INFORMATION** — 고객센터, 운영 시간, 입금 계좌 안내
- **BEST 상품** — 티셔츠 · 바지 · 스커트
- **REVIEW** 섹션

<br>

## ✏️ 배운 것

- 시맨틱 태그 `<header>` `<nav>` `<main>` `<section>`
- 정의 목록 `<dl>` `<dt>` `<dd>`로 상품 카드 만들기
- 이미지 배치와 기본 스타일링
